# 实验原始产物

真实 vLLM 的 G0 离线和流式功能验证保存在本机 `results/g0/`，环境取证在 `env/`。后续性能实验每次使用独立目录，保存命令、环境锁、负载轨迹及哈希、客户端逐请求 JSONL、服务端事件 JSONL、统计与图表。

- `results/g1/fixed-96/` 保存原版阻塞复现与容量对照。
- `results/g2/competition-02/` 保存最终策略的短轨迹、绑定验证和完整事件。
- `results/g3/paired-01/` 保存正式配对评估，按 seed、模式和场景组织。根目录包含冻结配置及分析产物。
- `results/g3/clean-01/` 保存干净环境复跑的依赖安装记录和三模式结果。
