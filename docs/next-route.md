# 项目节点

容量边界、完整顺序和短前缀消融已完成。短前缀实验只重排开头四条，后续 60 条逐条一致，六个固定容量配对中，冷前缀均使后续热门 P95 上升、冷门 P95 下降。作品集首页使用这一结果讲解多 LoRA 准入。 [容量边界](g3-capacity-boundary.md) · [完整序列](g3-arrival-order.md) · [短前缀](g3-prefix-order.md)
