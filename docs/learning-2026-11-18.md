## 教学可直接用的三组对照

1. **请求并发和 LoRA 名额。** A 四条、B 三条、C 一条占了多少？参考答案：八个请求位置，三种 LoRA。放宽种类上限也需要等待一个请求位置。
2. **B1 与 B2。** A 自然排空后，较早入队的 A 和触发排空的 C 均能准入，谁先检查？参考答案：B1 沿用队列检查，B2 先给 C 一次原版准入检查。
3. **P95 与 Goodput。** 18 秒窗口内达标数从 13 降到 11，吞吐变化怎么算？参考答案：Goodput 从 13/18 降至 11/18 条/秒，降幅 2/13 约 15.4%。总完成数可以持平。
